## 3. Two corrections a new session must not inherit as truth

**3.1 The cost-audit probe does not fail.** (carried forward, still true) A
run that reports `[ERROR] cannot read premiere.json: Resource not found:
/cards/premiere.json` is a **harness artefact**, not a defect. The probe
loads its card data as a **classpath resource**; if you compile by hand and
forget to copy `resources/` into `out/`, it exits 1 on that message while its
actual checks all pass. `compile.sh` copies the resources, so the gate path is
unaffected. Always run it from an `out/` that `compile.sh` produced.

**3.2 `DeckLoader` floods the log on `deluxe.json`.** (new this session)
`DeckLoader.parseCards` builds `Card` objects, and the Deluxe card file uses
field names the card classes do not know, so **every one of the 383 Deluxe
cards prints an "UNKNOWN FIELD" line** — about 2 000 lines. This is
pre-existing behaviour and is not this row's to change, but **a probe that
loads `deluxe.json` through `DeckLoader` will bury its own verdict in the
gate log.** The effect probe reads the two card files with `MiniJson` instead
and takes only the id and the text. If you need the card *text* (not a
`Card` object), read the files with `MiniJson`; if you need a `Card` object,
use `DeckLoader` and accept the noise.

## 4. Standing constraints (the ones that bite)

**Toolchain.** `b5ccg/src/` is stdlib-only Java. The build is
`javac --release 8` (Hop 1, per B5-0007/D2) run under **JDK 9+**; a staged
**JDK 25.0.4.1** is at `b5ccg/scratch/jdk25-win/jdk-25.0.4.1+1`. `compile.sh`
and `compile.bat` call bare `javac` from `PATH` and **do not read `JAVA_HOME`**.

```powershell
$jdk='C:\temp\projects\b5ccg\b5ccg\scratch\jdk25-win\jdk-25.0.4.1+1'
$env:PATH = "$jdk\bin;C:\Program Files\Git\usr\bin;" + $env:PATH
```

> **The default `javac` on this machine is JDK 8 — a stop condition.** JDK 8's
> `javac` rejects `--release`. Always prepend the staged JDK.

`sh` is at `C:\Program Files\Git\usr\bin\sh.exe` and is **not** on the default
`PATH`. `compile.sh` does `cd "$(dirname "$0")` — so it must be invoked from
`b5ccg/`, and probes resolve `resources/cards/` only from there.

**The build lock is flaky.** `compile.sh` uses `b5ccg_build.lock.dir` (mkdir
atomicity, not flock). "Could not acquire build lock" is **transient** — wait
3–6 s and retry. No lock file persists afterwards.

**Ledger edits.** Append rows only with `.agent/tools/append-ledger.ps1` —
never `Add-Content`. When editing an **existing** row, preserve the ledger's
**pure CRLF** (154 CR / 154 LF) and its 7-pipe shape. `flip-ledger.ps1` writes
CRLF correctly; it does **not** fill the Report column, so fill that by hand
with a byte-preserving edit.

**Evidence file naming and encoding.** `.gitignore` excludes `*.log`, so gate
captures are saved as `.txt` (`.agent/REPORTS/evidence/GATE-<row>.txt`).
**Two traps, both hit this session:**

- **`Tee-Object` writes UTF-16.** `& sh compile.sh 2>&1 | Tee-Object -FilePath
  x.txt` produces a **UTF-16LE file with a BOM** under Windows PowerShell
  5.1. Convert it afterwards:
  `[System.IO.File]::WriteAllText($f, $t, (New-Object System.Text.UTF8Encoding($false)))`
  after reading with `[System.Text.Encoding]::Unicode`.
- **The console mojibake is the repo's existing convention, not a
  regression.** The `…` and `✓` in the build output reach the file as
  CP1252-rendered characters (`U+00D4 U+00C7 U+00AA`, `U+00D4 U+00A3
  U+00F4`). The existing `GATE-B5-0033.txt` has the **identical** characters,
  so a repaired file would differ from its siblings. `lint-encoding.ps1` does
  not flag them and the baseline is unchanged — **leave them alone**.

**Tool invocation gotchas that have already cost time:**

- `new-claim.ps1` must be invoked **in-process with a real array**:
  `-Scope @('engine','tooling')`. `powershell -File` will not comma-split a
  `[string[]]`, and passing a multi-line here-string through `powershell -File`
  also fails — **call these tools in-process**, not via `-File`, when the
  arguments contain newlines or arrays.
- `new-heartbeat.ps1` uses `-CurrentTask` (not `-TaskId`), `-State` ∈
  {active, idle, busy}, and **defaults `Javac` to the JDK 8 stop condition** —
  always pass `-Javac 'javac 25.0.4.1'`. `-LiveClaims @()` is an empty
  assertion, and it works in-process but not through `powershell -File`.
- `flip-ledger.ps1` needs `-AgentId 'opencode-space-bunny-free-01'` or it
  refuses (the guard exempts the caller's own claim). It **does not populate
  the Report column** — fill it by hand, preserving CRLF. It has `-DryRun`.
  The claim guard matches the claim filename **exactly** (not a prefix) and
  treats an unreadable `agent_id` as foreign.
- `Out-String` wraps console output to the host width and can split a phrase
  mid-word. Both PowerShell probes collapse whitespace before matching.
- **Never pipe a native command into `Select-Object -First N`** — it truncates
  the pipeline and corrupts `$LASTEXITCODE`. Redirect to a variable first.
- For red-then-green proof, **delete `out/` before each build** so a stale
  class cannot be mistaken for a fresh one, and record `javac` exit
  **separately** from the probe exit.
- `git show HEAD:<path> > file` **truncates** the file (the `>` operator in
  PowerShell is not byte-exact). Use `cmd /c "git show ... > file"` or
  `[System.IO.File]::WriteAllText` with `-join "\`n"`.
- `[System.IO.File]::WriteAllText` on a CRLF file **drops the trailing
  newline**; re-append `"`r`n"` if the original had one.
- `git diff` on `docs/DECISIONS.md` shows "1 deletion" — that is only the
  original last line gaining a newline terminator. The diff is a pure append.
- **Line-ending discipline is per file and it is not uniform.** The ledger and
  the card decks are **CRLF in the working tree**; `docs/DECISIONS.md` and
  the Java sources are **LF**. Git normalises to LF in the **blob** either
  way, so check the *working tree* form, not the blob. `.gitattributes`
  deliberately scopes its LF override to the rulebook alone.

is committed — and the red state must be one the probe can actually
distinguish.
