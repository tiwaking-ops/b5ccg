# B5-0106 - Fleet operating files the fork left behind

## Changes made (all in claimed scope `tooling`)

### 1) `.agent/run-queue.ps1` — four fixes

**a) Default CLI changed from `freebuff` to `opencode`, default args `'run --auto'`.**
The queue runner now launches `opencode run --auto` by default, matching the operator prompt that says "opencode or any client with a read tool: start the session in the repo root and say `Read .agent/AGENT_PROMPT.md and follow it exactly.`"

**b) `$TaskPromptTemplate` rewritten.** Replaced the stale instruction "read `.agent/AGENT_LOOP.md`" with:
> Read .agent/AGENT_PROMPT.md and follow it exactly. The runner has pre-selected task `__TASK_ID__` for this session: .agent/CLAIMS/__TASK_ID__.json is absent and the row in .agent/TASK_LEDGER.md still reads OPEN. Re-verify both, then claim it, work ONLY inside the claimed scope, run the verification gate (RUN_TESTS=1 sh compile.sh) with the JDK 25 on PATH, write your report at .agent/REPORTS/<date>-<agent-id>-__TASK_ID__.md, flip the ledger row to DONE, delete your claim file, and refresh your heartbeat. ONE TASK PER SESSION, then exit.

**c) `$SeedPromptTemplate` rewritten.** Same `AGENT_LOOP.md` reference replaced with `AGENT_PROMPT.md` STEP 0 seed duty. The seed procedure itself (ground one useful task, write one OPEN row, run dup-census, verify with ledger-query) is unchanged.

**d) `AgentArgs` splitting fixed.** The code `$argList += $AgentArgs` passed the entire string as one argument, so `'run --auto'` arrived as a single `"run --auto"` token that `opencode` could not parse as two flags. Changed to `$argList += $AgentArgs.Split()` in both the task invocation path and the seed invocation path, so `run` and `--auto` are separate argv entries. The existing quote-neutralisation (`$prompt -replace '"', "'"`) is preserved.

**e) `Set-Location -LiteralPath $RepoRoot` added.** Ensures every launched `opencode run` starts in the repo root, since `opencode run` has no `--cwd` flag and uses the working directory as its context root.

### 2) `b5ccg/compile.sh` — wired in `test-boot-files.ps1`

Added `../.agent/tools/test-boot-files.ps1` to the `TOOL_PROBES` line so the boot-files gate probe runs automatically in every verification pass.

## Reusable lesson
The loop is a shell script, not an LLM: `run-queue.ps1` launches one `opencode run --auto` process per task, each fed the prompt "Read .agent/AGENT_PROMPT.md and follow it exactly." The prompt's `__TASK_ID__` placeholder is replaced per-iteration and passed as a single argv entry (with quote-neutralisation). `--auto` is required because the loop is unattended; a missing-permission prompt would stall the loop forever. `AgentArgs` must be split on whitespace — a single-string pass makes `run --auto` arrive as one unparsable token.
