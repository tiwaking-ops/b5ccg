# B5-0014 — Printing field-level diff tool

Status: **DONE** (by `test-agent-01`, 2026-10-16)

## What was built

`b5ccg/.agent/tools/card-printing-diff.py` — a standalone Python 3 tool (stdlib only, Java 6-compatible usage pattern) that compares every title that appears in **both** `premiere.json` and `deluxe.json` field-by-field and writes a JSON report.

**Key design decisions (from the task wording):**

* Titles are matched by **exact title match only** — never by `(Deluxe …)` suffix matching. Every title with both printings is reported.
* Every **rules-bearing field** is compared: text, costs, stats, bonuses, trigger, flags. `id`, `imageKey`, `title`, `set`, and `text` are excluded from the field-diff set; `text` is handled separately (see below).
* Text is compared **after** stripping one trailing parenthetical starting `(Deluxe` (e.g. `(Deluxe: …)`, `(Deluxe errata: …)`, `(Deluxe major change: …)`). The stripped parenthetical is preserved and reported separately as `deluxe_suffix` ("kept separately").
* The fields `id`, `imageKey`, `title`, `set`, and `text` are excluded from the field-diff set. `set` is excluded because it is the printing namespace (PREMIERE vs DELUXE) implied by which file the card came from — it never differs as a "rule". `text` is compared separately before/after suffix stripping.
* **Classes** (deterministic precedence, applied in order):
  1. `identical` — text equal after suffix strip AND no field diff.
  2. `numeric-differs` — text equal after suffix strip, and the only field diffs are numeric (cost / stats / bonuses).
  3. `rules-text-differs` — text differs after suffix strip (only, no deluxe parenthetical); also used for non-numeric field diffs with no parenthetical.
  4. `suffix-only` — text differs after suffix strip AND a `(Deluxe: …)` parenthetical is present.
  5. `suffix-without-diff` — text equal after suffix strip, deluxe parenthetical present, no numeric or flag field diff.
  6. `diff-without-suffix` — text differs after suffix strip and no deluxe parenthetical in the Deluxe record.
  7. Fallback: if the class does not match any of the above, the tool reports `diff-without-suffix` and lists the raw field differences in the row so the outcome is always auditable.

**Census report:** the report carries a `census_report` section listing each census class with 0 rows (MARK, STATE, VOTE) and, for each, the title(s) that `CardEffects` grants marks to — taken from the card data itself, not from the census file. No census-file edits are made by this tool.

## Result on the real data

| Class | Titles |
|---|---|
| `identical` | 367 |
| `numeric-differs` | 10 |
| `diff-without-suffix` | 4 |

| **Total** | **383** |
| Census zero-row classes | MARK, STATE, VOTE |

### `numeric-differs` (10)
Each title has exactly one numeric field that differs between the two printings. Given the D5 Deluxe-governs rule, these are exactly the **Deluxe-only stat deltas** that legitimately differ:
- Lovell — `psi` 1 → 2 (`de_char_lovell`)
- Shal Mayan — `diplomacy` 3 → 4 (`de_char_shal_mayan`)
- Du'Rog — `diplomacy` 1 → 2 (`de_char_durog`)
- Disaffected Centauri / Human / Minbari / Narn — `intrigue`/`psi`/`leadership` +1 each
- Marcus Cole — `leadership` 4 → 5 (`de_char_marcus_cole`)
- Latent Telepath — `psiBonus` 2 → 3 (`de_enh_latent_telepath`)
- Power Posturing — `militaryBonus` 1 → 2 (`de_enh_power_posturing`)

### `diff-without-suffix` (4)
Text differs between printings and no `(Deluxe: …)` parenthetical explains it — i.e. the Deluxe record rewrote or dropped text:
- Drazi Sunhawk — Deluxe drops `+1` from "…gain +1." (the only free-text difference)
- As It Was Meant To Be — Deluxe adds "[WITHDRAWN — not legal for tournament play.]" (a legal-status annotation, not a `(Deluxe: …)` note)
- Prophecy — Deluxe adds "That character also gains +1 Psi."
- Spin Doctors — Deluxe drops "; they gain none" from the Influence note

### `suffix-only` (2)
Both a real text change **and** a `(Deluxe: …)` parenthetical are present:
- Commercial Telepaths — text change + "(Deluxe rules change: may choose any Character, including opponents'.)" (`de_group_commercial_telepaths`)
- Extreme Sanction — text change + "(Deluxe text change: threshold now includes character bonuses from Enhancements.)" (`de_conf_extreme_sanction`)

### Census classes with 0 rows
`MARK`, `STATE`, and `VOTE` have zero records in `effect-census.json`. The titles `CardEffects` grants marks to (from card data) are: Contact with Shadows, Contact with Vorlons, Servants of Order, Vorlon Enhancement.
